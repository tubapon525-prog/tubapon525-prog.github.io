プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-10-30

1. このツールについて / About

sns-auto は、運営者本人が作成した動画を、運営者本人のYouTubeチャンネルに投稿するための個人用ツールです。一般の利用者には提供していません。

sns-auto is a personal tool used only by its owner to upload the owner's own videos to the owner's own YouTube channels. It is not offered to the public.

2. YouTube API サービスの利用 / Use of YouTube API Services

このツールは YouTube API サービスを利用しています。利用にあたり、YouTube 利用規約およびGoogle プライバシーポリシーが適用されます。

This tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service and the Google Privacy Policy.

3. 取得する情報 / Information accessed

運営者本人のチャンネル情報と、動画のアップロードに必要な権限のみを使います。視聴者や第三者の個人情報は取得しません。

The tool only accesses the owner's channel information and the permission needed to upload videos. It does not collect personal information about viewers or any third party.

4. 情報の保存と共有 / Storage and sharing

認証情報は、運営者のみがアクセスできる暗号化された場所に保存します。取得した情報を第三者に販売・共有することはありません。

Credentials are stored in an encrypted location that only the owner can access. No information is sold or shared with third parties.

5. アクセス権の取り消し / Revoking access

Google アカウントのセキュリティ設定から、いつでもこのツールのアクセス権を取り消せます。

Access can be revoked at any time from the Google Account permissions page.

6. お問い合わせ / Contact

各チャンネルのSNSアカウントへのメッセージでお問い合わせください。

Please contact us via direct message on our social media accounts.
